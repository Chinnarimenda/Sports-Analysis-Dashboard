# 🏅 Sportsman Analysis Dashboard

This repository contains an interactive dashboard built to analyze and visualize data about international sportsmen and sportswomen. The dashboard provides insights into demographics, physical attributes, and sports distribution across countries.

## 📊 Project Overview

The goal of this project is to transform a raw dataset of athletes into a meaningful, interactive dashboard that helps users explore:

- Distribution of athletes by country, gender, and sport
- Physical characteristics like weight, eye color, and blood type
- Salary comparisons across sports and regions
- Zodiac and birthdate patterns
- Sport-specific participation trends

## 📁 Dataset

The dataset is provided in Excel format and includes the following fields:

- Member ID
- Full Name (Prefix, First Name, Last Name)
- Birthdate and Zodiac
- Gender
- Country Code and Name
- Language
- Email (excluded from visuals)
- Weight
- Eye Color
- Blood Type
- Sport Location
- Sports
- Salary

> 📌 Note: Sensitive fields like email are excluded from visualizations to preserve privacy.

## 🚀 Features

- Country-wise and gender-wise athlete distribution
- Sport popularity by region
- Weight and salary distribution histograms
- Eye color and blood type pie charts
- Zodiac sign frequency
- Interactive filters for country, gender, and sport

## 🛠️ Tech Stack

- **Python** (Pandas, Plotly, Streamlit or Dash)
- **Excel** for data input
- **GitHub** for version control and collaboration
